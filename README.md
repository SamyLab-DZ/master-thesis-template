# Modèle LaTeX pour mémoire de Master

Ce dépôt propose un modèle LaTeX destiné à la rédaction de mémoires de Master. Il fournit une base structurée et personnalisable pour la présentation des travaux universitaires.

## Fonctionnalités

- Organisation du mémoire en chapitres et sections.
- Mise en forme des figures, tableaux, équations et références bibliographiques.
- Code source LaTeX modifiable.
- Génération du document final au format PDF.

## Prérequis

- Une distribution LaTeX : TeX Live ou MiKTeX.
- Un éditeur LaTeX, tel que TeXstudio.

## Utilisation

1. Cliquez sur **Code → Download ZIP** pour télécharger les fichiers.
2. Extrayez l'archive dans un dossier local.
3. Ouvrez le fichier principal `.tex` avec TeXstudio.
4. Compilez le document pour générer le PDF.
5. Personnalisez le contenu et la mise en forme selon vos besoins.

Veillez à conserver tous les fichiers nécessaires à la compilation.
